# Android Client Configuration Guide (Joiner)

Follow these required steps to connect an Android smartphone to the WhitelistBypass tunnel.

---

## 1. Disable Android Private DNS (Critical!)

By default, Android attempts to encrypt DNS queries using DoT (DNS-over-TLS) on port 853 of the mobile carrier's resolvers (e.g., MTS `213.87.x.x:853`). Under strict mobile carrier whitelists, these DoT queries fail to reach resolvers and hang. As a result, Android assumes there is no Internet connection and blocks application traffic.

1. Open **Android Settings** $\to$ **Network & internet** (or *Connections*).
2. Locate **Private DNS**.
3. Set it to **Off**.

---

## 2. Install WhitelistBypass App

1. Download the latest Joiner APK from [WhitelistBypass Releases](https://github.com/kulikov0/whitelist-bypass/releases).
2. Install the APK on your Android device.

---

## 3. Configure the Application

1. Open the WhitelistBypass application.
2. Tap **Settings** (gear icon):
   - **DNS:** select `Custom` and specify `77.88.8.8` (Yandex DNS) or `8.8.8.8` (Google DNS).
   - **IPv6:** set to **Off**.
   - **Engine Mode:**
     - For Yandex.Telemost: `Video` (VP8 video stream).
     - For VK Calls: `DataChannel` (SCTP DataChannels).
3. Return to the main screen.
4. Paste the conference room link or scan the QR code generated by the server:
   ```bash
   whitelist-bypass qr <username>
   ```
5. Tap **START / GO**.
6. Confirm the Android system VPN profile creation prompt on first launch.

---

## 4. Verification

- A VPN key icon will appear in the system status bar.
- Open a browser and visit any site blocked by the carrier whitelist (such as `https://2ip.ru` or `https://habr.com`).
- Verify that your outbound public IP matches the IP address of your VPS.
