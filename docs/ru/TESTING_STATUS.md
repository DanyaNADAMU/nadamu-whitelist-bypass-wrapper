# Матрица готовности и тестирования функционала

В данном документе фиксируется актуальный статус реализации и тестирования компонентов проекта **Iris (WhitelistBypass Wrapper)** в боевом окружении.

**Тестовый сервер:** `berg` (Debian GNU/Linux 13 / Trixie x86_64, Linux 6.12)  
**Активный тестовый пользователь:** `danya`  
**Активный рабочий провайдер:** `VK Calls`

---

## 1. Системный слой и сервисы (Systemd & Creators)

| Компонент / Функция | Статус разработки | Статус тестирования (`berg`) | Примечания |
| :--- | :---: | :---: | :--- |
| Шаблон службы `whitelist-bypass@.service` | ✅ Завершено | ✅ Протестировано | Работает под пользователем `whitelist-bypass` с `NoNewPrivileges=true` |
| Поддержка провайдера **VK Calls** | ✅ Завершено | ✅ Протестировано | `headless-vk-creator` успешно генерирует ссылки и держит сессии |
| Поддержка провайдера **Яндекс.Телемост** | ✅ Завершено | ✅ Протестировано | `headless-telemost-creator` протестирован на этапе 1 |
| Поддержка провайдера **WB Stream** | ✅ Завершено | ⚠️ Ожидает кук | Сборка бинарника и логика готовы, ожидает реальных cookies |
| Поддержка провайдера **DION** | ✅ Завершено | ⚠️ Ожидает кук | Сборка бинарника и логика готовы, ожидает реальных cookies |
| Валидация cookies (>15 байт) | ✅ Завершено | ✅ Протестировано | Предотвращает запуск демона с пустыми заглушками |
| Синхронизация через `--write-file` | ✅ Завершено | ✅ Протестировано | Атомарная запись ссылки creator'ом в `current_link` |

## 3. Консольный интерфейс (CLI)

| Команда | Статус разработки | Статус тестирования (`berg`) | Примечания |
| :--- | :---: | :---: | :--- |
| `whitelist-bypass link <user>` | ✅ Завершено | ✅ Протестировано | Возвращает ссылку и статус сервиса |
| `whitelist-bypass qr <user>` | ✅ Завершено | ✅ Протестировано | Терминальный QR-код через `qrencode` и UTF-8 |
| `whitelist-bypass rotate <user>` | ✅ Завершено | ✅ Протестировано | Пересоздание чистой комнаты и обновление `room.env` |
| `whitelist-bypass provider <user> <p>` | ✅ Завершено | ✅ Протестировано | Смена платформы (проверено переключение на VK) |
| `whitelist-bypass status <user>` | ✅ Завершено | ✅ Протестировано | Полная диагностика: куки, служба, ссылка |
| `whitelist-bypass list` | ✅ Завершено | ✅ Протестировано | Таблица всех пользователей на сервере |
| `whitelist-bypass start/stop/restart` | ✅ Завершено | ✅ Протестировано | Управление службой пользователя в systemd |
| Флаг `--json` | ✅ Завершено | ✅ Протестировано | Работает на любой позиции аргументов |
| Fallback при остановленном демоне ядра | ✅ Завершено | ✅ Протестировано | Прямое in-process выполнение команд |
